Data City · build plan · Nov 2026

From tech demo to a city you want to play in

The web build already runs: a third-person analyst, a café, two NPCs and a SQL terminal. What it lacks is honesty underneath (grading, saves, login) and life on top (sound, crowds, a story that reacts). This plan fixes both in eight phases, each ending in something playable. Every task links to the files it touches, the problem it fixes, and what it depends on.

What the game is meant to become (core loop, analysis tiers, economy, characters, reactive streets) lives in the Data City Game Design page and in docs/game-design.md.
